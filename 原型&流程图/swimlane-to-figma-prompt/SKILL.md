# Swimlane To Figma Prompt

使用本 skill 将 Mermaid 泳道图产物转化为 Figma agent 可执行的复现提示词。

本 skill 不直接绘制 Figma 图，而是帮助用户让 Figma agent 基于模板重建可编辑泳道图。

## 输入要求

优先建议用户上传 SVG 格式的泳道图图片。

推荐输入优先级：

1. Mermaid `swimlane-beta` 代码。
2. 节点清单和连线清单。
3. SVG 格式泳道图图片。
4. 当前选中的 Figma 泳道图模板画框。
5. PNG 图片作为备用参考。

必须向用户说明：

- SVG 优先于 PNG。
- SVG 更适合作为布局参考，因为它保留矢量结构，放大不失真。
- PNG 只适合作为备用视觉参考，容易出现 OCR 错字、漏箭头或布局误判。

## 核心原则

Figma agent 复现时必须遵循：

- Mermaid 代码和节点/连线清单是流程真值。
- SVG 是布局参考。
- 当前选中的 Figma 模板画框是样式来源。
- 最终必须重建为可编辑 Figma 节点。
- 不得把 SVG/PNG 图片作为最终泳道图主体保留。
- 泳道数量不得少于两条，并且必须和 Mermaid 代码、节点清单中的角色保持一致。

## 模板样式来源

提示词中应要求 Figma agent 使用当前选中模板中的已命名样式节点。

预期模板节点包括：

- `泳道图模版`
- `泳道背景`
- `泳道分隔线`
- `泳道表头`
- `开始节点`
- `开始节点文本`
- `普通流程节点`
- `普通流程节点文本`
- `判断节点`
- `判断节点文本`
- `结束节点`
- `结束节点文本`
- `箭头连接线`

不要强制要求模板中存在 `条件标签文本`，除非用户明确说明已经添加。

## 箭头模板使用规则

提示词中必须明确：模板中选中的 `箭头连接线` 是可吸附到节点/组件的连接器模板，不是固定形状的箭头装饰。

Figma agent 复现时必须遵循：

- 使用模板中的箭头连接器能力，把箭头端点吸附到对应流程节点或判断节点上。
- 当节点位置、宽度、高度变化时，箭头应能跟随吸附端点自动调整路径。
- 不要把箭头拆成普通线段、固定矢量、固定 SVG 路径或不可随节点移动的装饰图层。
- 跨泳道连线也使用 `箭头连接线` 模板处理，保持可编辑、可重排。
- 分支标签可以独立为可编辑文本，但标签位置应跟随对应连接线附近布局调整。

## 输出 Figma agent 提示词

生成一段可直接复制给 Figma agent 的提示词。

提示词必须包含：

- 请基于当前选中的 Figma 模板画框进行复现。
- 请以 Mermaid 代码、节点清单、连线清单为流程真值。
- 请以 SVG 为布局参考。
- 请复制模板中的节点、文字、背景、泳道线和箭头连接线样式。
- 请重建可编辑文本、矩形流程节点、菱形判断节点、连接线和箭头。
- 请使用模板中可吸附、可随连接节点自动调节的箭头连接器，不要使用固定箭头形状或不可随节点移动的线段。
- 请不要保留 SVG/PNG 作为最终图层。
- 请保持至少两条泳道，并按 Mermaid 代码和节点清单中的角色顺序绘制。
- 请保持所有分支标签、回退线、取消线和跨泳道连线。
- 请确保所有文字完整显示且可编辑。

## 输出验收清单

在提示词之后，输出 Figma 复现验收清单：

- 所有文字均为可编辑文本。
- 没有把 SVG/PNG 作为最终泳道图主体保留。
- 泳道数量不少于两条，且角色名称和顺序正确。
- 节点所属泳道正确。
- 箭头方向与 Mermaid 流程一致。
- 箭头端点已吸附到对应节点，移动节点时箭头能自动跟随调整。
- 没有使用固定 SVG 路径、普通线段拼接或不可随节点移动的箭头装饰。
- 分支标签没有遗漏。
- 跨泳道连线使用 `箭头连接线` 模板，样式一致且可编辑。
- 节点样式与当前模板一致。
- 节点之间没有重叠。
- 连线尽量避开节点文字。

## 默认输出结构

```text
一、建议上传的图片格式
二、给 Figma agent 的复现提示词
三、Figma 复现验收清单
四、可选：模板命名检查建议
```
