# 示例：将订单退货泳道图复现到 Figma

## 用户输入

用户已经有：

- Mermaid `swimlane-beta` 代码。
- 节点清单。
- 连线清单。
- 从 Mermaid 在线编辑器导出的 SVG。
- Figma 中已选中的 `泳道图模版` 画框。

用户希望生成给 Figma agent 的提示词。

## 输出示例：建议上传的图片格式

建议上传 SVG 格式图片。SVG 比 PNG 更适合作为布局参考，因为它保留矢量结构，放大不失真；PNG 只建议作为备用视觉参考。

## 输出示例：给 Figma agent 的复现提示词

请基于当前选中的 Figma 画框「泳道图模版」，把我上传的泳道图 SVG 复现为可编辑的 Figma 节点。

要求如下：

1. Mermaid 代码、节点清单和连线清单是流程真值；SVG 只作为布局参考。
2. 不要把 SVG 或 PNG 作为最终泳道图主体保留。
3. 请重新创建可编辑文本、矩形流程节点、菱形判断节点、连接线和箭头。
4. 请使用当前模板中已经命名的样式节点：
   - `泳道背景`
   - `泳道分隔线`
   - `泳道表头`
   - `开始节点`
   - `开始节点文本`
   - `普通流程节点`
   - `普通流程节点文本`
   - `判断节点`
   - `判断节点文本`
   - `结束节点`
   - `结束节点文本`
   - `箭头连接线`
   - `跨泳道折线箭头`
5. 请保持至少两条泳道，并按 Mermaid 代码和节点清单中的角色顺序绘制。
6. 请保持所有分支标签、回退线、取消线和跨泳道连线。
7. 所有节点文字必须完整显示且可编辑。
8. 节点不要重叠，连线尽量使用正交折线并避开文字。
9. 如果模板画框高度不足，可以向下扩展画框高度，但不要改变模板宽度和泳道顺序。

## 输出示例：Figma 复现验收清单

- 所有文字均为可编辑文本。
- 没有把 SVG/PNG 作为最终泳道图主体保留。
- 泳道数量不少于两条，且角色名称和顺序正确。
- 节点所属泳道正确。
- 箭头方向与 Mermaid 流程一致。
- 分支标签没有遗漏。
- 跨泳道折线箭头存在且样式一致。
- 节点样式与当前模板一致。
- 节点之间没有重叠。
- 连线尽量避开节点文字。
