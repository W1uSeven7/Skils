## 文件说明

每个 skill 以独立文件夹保存，入口为 `SKILL.md`；原目录中的 `agents/`、`references/`、`scripts/` 和 `examples/` 等配套文件一并保留（如有）。使用时应保留整个 skill 文件夹。

本仓库同时收录个人编写和第三方来源的 skills，不将所有内容声明为原创。`grill-me` 的安装记录标明来源为 [mattpocock/skills](https://github.com/mattpocock/skills)。各目录已有的来源说明和版权声明保留在原文件中。
